  <p>Grow a second question only inside the low-study branch: <strong>absences ≤ 10?</strong> Student B (8 absences) enters one new leaf; student A (12) enters the other. C and D remain together. The three leaf predictions are 7, 10, and 15.5; the training SSE becomes 0.5.</p>

<section className={styles.chapter}>
  <h2 id="gradient">5 · Why is this called gradient boosting?</h2>
  <p>For half squared-error loss, differentiate with respect to the current prediction F. The negative gradient is exactly the residual used above.</p>
  <GradientMath />
  <p>A regression tree approximates that negative-gradient direction with a small, piecewise-constant correction. Each update changes the function; the next tree is fit to the new pseudo-responses.</p>
</section>

<section className={styles.chapter}>
  <h2 id="shrinkage">6 · What do repeated corrections add up to?</h2>
  <p>Keep the same split for every round. In a leaf with target mean μ, each update moves the current prediction a fraction η of the remaining gap. Starting from F₀, the gap shrinks geometrically.</p>
  <ShrinkageMath />
  <p>For the two leaves, the within-leaf SSE is 5. Initially, the distance between each leaf mean and the baseline is 3.5, and each leaf has two observations. After M updates the remaining between-leaf error is 49(1 − η)<sup>2M</sup>, giving the expression above. With η = 0.5, this matches the report’s <span className={styles.inlineMath}>5 + 49(0.25)<sup>M</sup></span>.</p>
  <div className={styles.result}>This closed form relies on the deliberately fixed split and squared-error loss. Real gradient boosting can change its split and feature at every stage; validation decides how many stages to keep.</div>
</section>

<section className={styles.chapter}>
  <h2 id="classification">7 · Classification uses pseudo-residuals too</h2>
  <p>For binary labels, let F(x) be the log-odds score and p(x) = σ(F(x)) the predicted probability. Under logistic loss, the next tree learns y − p: the gap between the observed label and its current probability.</p>
  <ClassificationGradientMath />
  <p>So the common recipe is not “fit a tree to the wrong answers.” It is: choose a loss, compute its negative gradient at the current predictions, and fit a small tree to approximate that correction.</p>
</section>
