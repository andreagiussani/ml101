## 1. What is Machine Learning?

<LearningQuestion />

A system can make predictions without learning from examples. For this chapter, use the following working definition:

> **A system learns from examples and uses what it learns to perform a task.**

## 2. When Did Machine Learning Begin?

In 1959, **Arthur Samuel** described work on giving computers the ability to learn without explicitly programming every action. His checkers program improved through experience. ([Samuel, 1959](#ref-samuel))

In 1997, **Tom Mitchell** made the idea more precise: a program learns from **Experience (E)** with respect to a **Task (T)** and a **Performance measure (P)** if its performance at the task, as measured by P, improves with experience E. ([Mitchell, 1997, Chapter 1](#ref-mitchell))

## 3. Machine Learning and Statistics

Machine Learning and Statistics overlap. Bayesian updating is one example of learning from evidence: new data update a belief about a hypothesis. In notation, `P(H | D) = P(D | H) × P(H) / P(D)`, where `H` is a hypothesis and `D` is observed data. The two fields are connected, but they are not identical.

Statistical explanation and prediction ask related but different questions. An explanatory analysis may ask which factors are associated with loan default and how uncertain that relationship is. A predictive analysis asks how well we can forecast default for an applicant we have not seen.

## 6. Why Did Deep Learning Accelerate?

([Krizhevsky, Sutskever & Hinton, 2012](#ref-krizhevsky))

Transformers arrived in 2017; GPT-3 followed in 2020. These developments built on earlier ideas and systems. ([Vaswani et al., 2017](#ref-vaswani))

## 7. Are Better Algorithms Always Better?

**Is a more sophisticated algorithm always a better decision?**

Models learn from the examples they receive. If data are biased, incomplete, outdated, or incorrect, predictions may be unreliable. A powerful model cannot guarantee that its examples represent the people or conditions where it will be used.

Return to the working definition: a system learns from examples to perform a task. What it learns, and whether that is useful, depends on the examples, the task, and how performance is judged.

### Three takeaways

1. Machine Learning did not begin with modern generative AI.
2. Progress reflects the interaction of ideas, data, and computing systems.
3. A powerful model does not automatically produce reliable predictions.
